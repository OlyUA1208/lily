# Lily — інтернет-магазин

Косметика, дитячі іграшки, декор і освітлення для дому.

- `index.html` — магазин
- `admin.html` — адмінка (вхід за паролем)
- `assets/config.js` — контакти й адреса Google Apps Script (`API_URL`)
- Серверна частина (Code.gs) живе в Google Apps Script, на GitHub її немає

Поки `API_URL` порожній, сайт працює в демо-режимі (пароль адмінки: `demo12`).
Покрокова інструкція запуску — в окремому документі «Lily — інструкція запуску сайту».
